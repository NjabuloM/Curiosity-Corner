# Notes

Topic notes, one per system or concept (for example `cardiovascular.md` or `feedback-loops.md`).

These are **not written in advance**. A note gets created when several answered questions point at the same system, and it pulls their findings together into one place.

A note can include:

- A short summary of what the system does and why it exists
- A diagram of its main parts
- Its key processes and feedback loops
- How it fails, and what compensates
- Links to the other systems it depends on or affects
- Links back to the questions that built it up
- Open questions
